# Audit snapshots

- `canonical-ecosystem-facts.json` é o snapshot mecânico **corrente** dos seis projetos definidos em `ECOSYSTEM_CHARTER.md` e é mantido por `scripts/sync_canonical_ecosystem_facts.py`.
- `ecosystem-facts.json` pertence à reconciliação F1 de 2026-08-17, que cobria nove repositórios. Ele permanece preservado como evidência histórica e não define mais o escopo canônico atual.

Nenhum snapshot mecânico pode adicionar/remover projetos do Charter ou promover estado científico/econômico.
